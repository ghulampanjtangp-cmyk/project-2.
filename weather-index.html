Isobar

Current conditions for any city, pulled live from OpenWeatherMap. Type a city name to get its temperature, humidity, and condition as of the last recorded reading.

Isobar calls the OpenWeatherMap API directly from your browser, so it needs your own free API key. Get one at openweathermap.org/api (the free tier is enough for this app), then paste it below. It's saved only in this browser via localStorage.
